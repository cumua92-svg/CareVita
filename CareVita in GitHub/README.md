# Care Vita – Dokumentations-App für Pflegekräfte

## ?? Überblick

**Care Vita** ist eine Mobile-First Dokumentations-App für ambulante Pflegekräfte (APDs).

### Kernfunktionen
- **Besuch-Dokumentation:** Pfleger dokumentiert Patienten-Visits direkt vor Ort
- **Tourenplanung:** Büro-Personal plant tägliche Routen
- **Patientenmanagement:** Stammdaten verwalten
- **Offline-Modus:** Funktioniert auch ohne Internet
- **Medifox-Integration:** Daten-Austausch mit bestehender Software

### Zielgruppe
- **Pfleger** (mobil, Smartphone/Tablet)
- **Büro-Personal** (Desktop, Tourenplanung & Admin)
